## Practical integration sequence
1. Reuse existing WPF/WebView2/NSIS, no shell replacement. Reusable GitLab/GitHub pipeline components + FlaUI/Playwright check frozen SHA.
2. Browser only adapt tabs/history from WebView2 example, do not bundle alternative browser engines.
3. One local inference Ollama, existing SQLite/RAG. Other RAG/memory stacks are evaluation references only.
4. Creative: use real full-page template, Comfy graph, editable PptxGenJS demo, Godot demo, Roblox official MCP. Separate staff agents before source edits.
5. Only downloads in isolated/pinned staging after rights and resource preflight; no automatic install, cloud spend or adult provider bypasses.
