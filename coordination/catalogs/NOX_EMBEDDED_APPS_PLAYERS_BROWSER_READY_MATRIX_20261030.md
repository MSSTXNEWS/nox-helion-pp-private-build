# NOX HELION · READY EMBEDDABLE APPS / PLAYERS / BROWSER / PAGE TEMPLATES · 2026-10-30

**Scope:** curated component-to-feature candidates, not a topic-dump. Verified against existing NOX source boundaries (WPF + WebView2 + NSIS OneHost, approved HOME/MENU/WORK/passport SHA, existing Ollama/RAG/events.v3, STOP/ACL), and Drive ALL PAGES MAX, MENU NAV TREE V2, Creative Studio V5 and Release 1 REV5. The master user requirement remains at least 3 candidates per feature; this file covers selected functions only, not total project requirement coverage.

**Status:** CANDIDATE/REUSE. Exact package licenses, security reviews, revisions, native Windows tests and plugin costs must be completed before installation. Some links are docs/sites; not all open-source or drop-in components. No product source tree or PR162 changed. Code from a full app is a reference unless its license and embedded integration are verified.

**Important recent finding:** Plyr is deprecated in favour of Video.js 10; DO NOT adopt Plyr for a new default player. Source: https://github.com/sampotts/plyr. WebView2Browser is Win32/C++ code; prefer reusing behaviors in existing WPF WebView2 instead of replacing OneHost. LibVLCSharp.WPF requires its native VideoLAN.LibVLC.Windows package and codec/license review.
