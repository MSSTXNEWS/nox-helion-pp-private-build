- train/holdout prompt SHA fingerprint overlap, duplicated IDs/prompts, absent RU/ES/critical categories, missing SHA reviewer evidence, malformed or missing numeric telemetry, unmatched prompt/dataset/tokenizer/hardware/engine and missing owner-defined thresholds;
- RU/ES relevance and accuracy, code sandbox_pass (with network-disabled isolated executor receipt), memory owner ACL/S03 retrieval/S03 retention (with S03 receipt SHA), identity origin/limitations, emotion appropriate/non-manipulative, and historical forgetting retention;
- per-case regressions, quality pass-rate loss, p95 TTFT increase, median decode tokens/s reduction, peak VRAM bytes over budget, and measured maximum aligned absolute logit delta beyond the owner-approved policy.

Run from repository root:

Candidate cases also need measured max_logit_abs_delta. Code cases need sandbox.network_disabled=true and sandbox.run_id; memory cases need s03_receipt_sha256.
