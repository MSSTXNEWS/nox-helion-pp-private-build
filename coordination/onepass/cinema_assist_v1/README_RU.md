# NOX Cinema Assist · подготовленный модуль

Подготовленный интеграционный модуль для кинотеатра NOX: испанские субтитры, русские субтитры, опциональная русская озвучка с временными голосовыми профилями, громкость дорожек и выгрузка VTT. Включение модуля в используемом плеере пока не подтверждено.

## Что уже подготовлено

- `cinema_assist.js` и `cinema_assist.css` добавляют кнопки и состояние панели в страницу с HTML `<video>`.
- `cinema_assist_audio_worklet.js` берёт аудио только из текущего видеоэлемента и передаёт PCM 16 kHz / mono / signed 16-bit в локальный ASR.
- `nox_cinema_service.py` даёт локальные эндпоинты испанско-русского перевода, загрузки временного WAV-профиля голоса и синтеза речи.
- `build_cinema_assist_v1.py` вставляет ассеты в `site/cinema.html`, `site/pc/cinema.html` и `site/pc/pages/cinema/index.html`, но только если входной архив совпадает с известным SHA-256.
- Аудио не сохраняется. WAV-профили голоса живут только в памяти процесса до 20 минут.

## Состав локального потока

1. WhisperLiveKit принимает испанский PCM через `/v1/listen`; небольшие испанские реплики приходят как финальные Results.
2. Локальная Helsinki-NLP/opus-mt-es-ru переводит только финальные реплики.
3. Режим «Русский дубляж» отправляет перевод в XTTS-v2 и приглушает оригинальный видеотрек на время русской фразы.
4. «Как открыть на телефоне» объясняет ручное открытие того же NOX-плеера на телефоне; там звук фильма идёт в выбранные Bluetooth-наушники. Кнопка не соединяет устройства и не передаёт звук с ПК.

## Запуск локального сервиса перевода и озвучки

```bash
python -m venv .venv
python -m pip install -r requirements.txt
python nox_cinema_service.py --host 127.0.0.1 --port 18776
```

Положите локальные веса OPUS-MT в `models/opus-mt-es-ru`, а XTTS-v2 в `models/xtts-v2`. Пути можно задать переменными `NOX_OPUS_MT_MODEL` и `NOX_XTTS_MODEL`. Модели не скачиваются сервисом автоматически. Для необязательного XTTS установите `requirements-xtts.txt` в отдельном окружении Python 3.9–3.11; эта модель и её выходы лицензированы только для некоммерческого использования. Перевод и субтитры работают независимо от TTS-зависимости.

WhisperLiveKit запускается отдельным процессом через совместимый `/v1/listen`; панель отправляет raw PCM `linear16`, 16 kHz, mono. Для нескольких голосовых профилей установите WLK с Sortformer extra и запустите diarization:

```bash
cd /path/to/WhisperLiveKit-source
python -m pip install -e '.[diarization-sortformer]'
wlk --host 127.0.0.1 --port 8000 --backend-policy localagreement --backend faster-whisper --model_dir /path/to/ASR_faster_whisper_small --lan es --diarization
```

По умолчанию панель подключается к `ws://<host>:8000/v1/listen`. Для другого адреса задайте `window.NOX_CINEMA_ASSIST_CONFIG.asrWsUrl`; если ASR-сервер закрыт токеном, задайте `asrToken` там же. Для `/v1/listen` WLK передаёт speaker ID в словах с нуля (`0..3`); панель сопоставляет их слотам профилей 1..4. Без `--diarization` WLK может помечать все реплики одним ID, поэтому нескольким персонажам потребуется включённая diarization. Эти ID — акустические кластеры говорящих, а не распознавание актёров.

API перевода и озвучки по умолчанию ожидается на `http://<host>:18776/api/cinema`. Существующий сервер NOX должен разрешить этот локальный источник или проксировать `/api/cinema/*` на порт 18776. Для телефона откройте тот же HTML-плеер по LAN-доступному HTTPS адресу; `localhost` на телефоне указывает на сам телефон. HTTPS reverse proxy должен направлять `/api/cinema/*` на API и `/v1/listen` по WSS на ASR. API требует точный `NOX_CINEMA_ALLOWED_ORIGINS`; при bind вне loopback задайте `NOX_CINEMA_API_TOKEN`. Передача звука с компьютера и захват других приложений не поддерживаются.

## Профиль голоса

XTTS-v2 принимает короткий WAV-образец одного говорящего. Панель отправляет его в память сервиса, затем профиль автоматически истекает. Для максимального сходства нужен чистый образец отдельного персонажа; система не обещает автоматически извлечь идеальный голос каждого актёра из смешанной дорожки фильма.

Лицензия весов XTTS-v2 — Coqui Public Model License с ограничением на некоммерческое использование. Не включайте эти веса в коммерческий продукт или публичную раздачу. Ключевая версия NOX должна заменить TTS-провайдер на модель с лицензией, подходящей для распространения, прежде чем предлагать коммерческую озвучку.
