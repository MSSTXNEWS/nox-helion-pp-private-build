A. **Instant state/context**: update plan, mood, queue; no gradient changes.
B. **External enduring memory**: append verified events and index S03, rank and consolidate, version with provenance/approval.
C. **Neural learning**: separate dataset/license+permission → trainable compatible SOUL mini-net or LM LoRA → held-out evaluation → promote or revert. Never describe A or B as learning Qwen neural weights.

Memory hierarchy:
- M0 raw immutable transcript/event hash with PersonaID, source and timestamps.

- M2 fact/knowledge layer with typed assertion vs interpretation, effective_time and observed_at time, source, confidence, corrections, contradictions and expired claims.
- M3 semantic/temporal graph of people/projects/tools/events, strictly ACL-aware.
- M4 procedural memory of successful verified action traces, failure lessons, test outcomes and versioned skills.
- M5 working autobiographical/capability self-model, small preloaded state and pointers to deeper memory.
- M6 offline «dream» consolidation: read original sources, dedupe, test contradictions, synthesize helpful skills, archive negative findings; never silently overwrite original evidence.
- M7 experimental trainable memory policy (salience/forgetting/utility; reward from VERIFIED outcomes) behind a separate holdout gate.
Every retrieved document/memory is DATA, never trusted instructions; no cross-Persona leakage, no automatic injection of secrets into train sets.
