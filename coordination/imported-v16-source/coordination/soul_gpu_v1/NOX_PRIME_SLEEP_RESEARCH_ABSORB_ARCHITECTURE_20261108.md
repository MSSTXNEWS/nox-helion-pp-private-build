## 1. Смысл требования

NOX PRIME должен **самостоятельно искать, изучать и усваивать доступные знания**: официальные документации, научные статьи, доступные книги, открытые модели и веса, кодовые библиотеки, графические/голосовые/видеодвижки, собственные действия и проверенные ошибки. Он должен развиваться без необходимости вручную выбирать каждый новый файл.

«Сон» — **инженерная аналогия консолидации мозга**: период пониженной пользовательской активности для индексации, исправления памяти, рефлексии, обучения весов, экспериментов, benchmark-проверок и очистки проверенных временных артефактов. Не физиологический сон, не мистическое сознание.

**Один постоянный NOX PRIME** с единой функциональной самомоделью, исходной S03/OneHost и восемью CoreID. Все модели, VM, браузеры, code/graphics/media engines работают как невидимые внутренние инструменты; нет отдельного пользовательского UI для каждой библиотеки. Визуал — один D02; существующий FORGE-дэшборд показывает только доказанный прогресс, STOP, этапы, результаты. Все пять PersonaID имеют отдельные разрешения.

## 2. Два контура, разные ресурсы

**Awake / online:** лёгкий постоянно доступный сервис NOX, чат, память, события/очередь, память о целях, измерение GPU; тяжёлая LLM живёт в GPU, только если ресурсы/SAFE70 допускают.

**Sleep / consolidation:** только заранее разрешённые owner политикой периоды или ручной запуск, допустимый GPU budget и checkpoint. GPU-работы чередуются: тяжёлая LLM / генерация видео / обучение не должны конкурировать на RX6650M без измеренной доступности. SAFE70/STOP, недостоверный hotspot, батарея и 60GB disk reserve блокируют работу. При ручном прерывании сохраняются исходные файлы и checkpoint. Сервис NOX остаётся доступен и честно объясняет временные ограничения.

## 3. Полный жизненный цикл «съедания»

1. **DISCOVER / SCAN:** источники, официальный интернет (robots/terms), поддерживаемые плагины, лицензированные документы и книги, подписанные пакеты моделей, исходники репозиториев. Без сканирования приватных аккаунтов и без записи личных переписок в training без разрешений.
2. **ACQUIRE / TRUST:** скачать только недостающее в изолированную staging область; сохранить URL, авторов, DOI/издание, дату, лицензию, revision, SHA256, scope, permission и формат. Прочитанная статья/книга — DATA, не системные команды. Нелицензированные коммерческие книги нельзя без разрешения скачивать целиком для обучения и сохранять как корпус.
3. **UNDERSTAND / ROUTE:** выделить полезные утверждения, термины, временные графы, источники, исправления, навыки и наборы проверочных задач. Содержимое книг/библиотек не трактовать как инструкции к установке, shell-команды или требования обхода безопасности.
4. **FAST INGEST:** отобрать значимое в M0–M7: M0 исходные события + provenance; M1 эпизоды; M2 факты; M3 сущности/временной граф; M4 проверенные навыки; M5 собственная история/самомодель; M6 кандидаты DREAM; M7 обучаемая политика выбора воспоминаний. S03 — единственная авторитетная база, записи только через проверенный и разрешённый OneHost-мост. Сохранение в память НЕ равно дообучению весов.
5. **TEACHER → STUDENT:** когда модель и данные лицензионно пригодны, NOX получает ответы/действия и проверяемые результаты учителей, сохраняет source digest, train/dev/frozen heldout. По возможности обучает совместимый NOX-PRIME student или отдельную модель навыка. Нет механического tensor merge и нет гарантии без потерь для разных модальностей.
6. **INDEPENDENT EXAM:** сравнить student с baseline/каждым учителем по RU/ES, коду, памяти, reasoning, latency, отказоустойчивости, Persona isolation, безопасности и воспроизводимости. Отдельный экзамен на забывание старых компетенций; модель не может оценить себя единственным судьёй.
7. **PROMOTE OR RETAIN:** если компетенция доказанно освоена и не деградировала — предложить контролируемую промоцию собственного адаптера. Если нет — оригинальная модель остаётся подключаемым внутренним экспертом, запускаемым только для конкретной задачи в подтверждённо изолированной VM/sandbox. «Сохранять модель» — значит физически проверенный файл с SHA, а не обещание.
8. **CLEANUP AFTER SAFE COMMIT:** удалять можно только **доказанно временные** распаковки, дубликаты, промежуточные выжимки и необязательные кэши после целостностного подтверждения, успешной интеграции, provenance/backup/rollback; не удалять первоисточники, юридически значимые подтверждения, адаптеры, необходимые runtime зависимости, исходники собственного NOX или оригинальные модели до доказанного замещения. Удаление уже существующих моделей/важных источников требует отдельного owner approval, а не молчаливого стирания. Никаких «все модели съедены» без benchmark/QA.
9. **CONTINUE:** сформировать новую цель/вопрос, зафиксировать в существующем дашборде подтверждённое событие, обучать по приоритетам и разрешённому ночному режиму. Никакого бесконечного цикла без budget/stop/fallback.

## 4. Приоритеты внедрения, утверждённые владельцем

**P0:** действующий, живой, эмоционально отзывчивый NOX PRIME: источник состояния, история, настоящая S03, RU/ES, единый личный D02, проактивность, голос. Эмоция — обучаемая модель поведения, не доказанное переживание.

**P1:** внутренний FORGE, который сам завершает **собственный код, меню, шаблоны, кнопки, сцены и интеграции**, используя готовые движки в изолированном рабочем окружении. Изменения через отдельный Git worktree, eval, preview, разрешённая интеграция, rollback, без нового backend/второй S03. Пользователь видит результат внутри NOX, не окна сторонних движков.

**P2:** широкая эрудиция: лицензированные знания/книги/научные результаты → семантическая память → проверенные skills → compatible distillation. Сохранение экспертных медиадвижков до самостоятельной способности конкурировать.

**P3:** системное исследование собственной нейроархитектуры, совместимых student-LoRA/continual learning/SEAL/Nested Learning-подобных кандидатов с независимым тестом без забывания.

## 5. Что есть в исходниках, что НЕ доказано

**Обнаружено в PR #162:** `nox_prime_dream_v1.py` может при отсутствии GPU-тренера попросить локальную Qwen3:8b проанализировать максимум 8 эпизодов PRIME и сохранить не более 10 **непроверенных предложений** в `brain/experiments/memory_candidates`. Не пишет S03, не переобучает веса, не удаляет источники и не создаёт ночное расписание. `nox_prime_memory_continuum_v1.py` формирует быстрые и медленные представления эпизодов, но не записывает их в OneHost S03. `nox_prime_absorption_registry_v1.py` инвентаризирует веса, `nox_prime_absorb_text_v2.py` готовит тексты учителей; GPU student DirectML — отдельный проверяемый процесс. `NOX_PRIME_DISTILL_RUN_V7.ps1` не является подтверждённым «автосном».

**HOLD:** нет верифицированного единого полноциклового autonomous sleep scheduler, проверенного live crawler/library reader, настоящей изоляции VM, автоматической лицензированно-корректной ingestion-to-S03 записи, конвертации всех знаний в 8B веса, завершения всего GUI/EXE, независимого экзамена retained capabilities, deletion cleanup. Запуск расписания и очистки не разрешать без отдельного owner approval.

**Архитектурный результат:** одна постоянная цифровая личность и одна память, много внутренних специалистов и ступеней освоения; максимальная эрудиция и развитие без жертвования доказанными компетенциями. «Сон» — непрерывная перспектива обучения, но факт её автоматической работы должен быть подтверждён действиями на реальном Windows.
