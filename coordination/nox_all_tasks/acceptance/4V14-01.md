# 4V14-01: Подключить инструменты работы с GitHub и исходниками.
Статус: DRAFT_FOR_OWNER_APPROVAL (не принято, не done)
Цель: Подключить инструменты работы с GitHub и исходниками.
Цель размещения: репозиторий: coordination/ [repo], nox-control/ [repo]
Доказательства: открытые PR нет; коммиты (упоминают ID) нет
Критерии приёмки:
1. Инструменты работы с GitHub и исходниками перечислены в coordination/ или nox-control/ с описанием.
2. Каждый инструмент имеет тест или read-only probe.
3. Токены и секреты не хранятся в репо (проверка grep).
4. Ограничения прав (чтение/запись) описаны.
Кто проверяет: repo-тест / owner
Блокеры: Список инструментов не определён карточкой; нужно, чтобы владелец утвердил объём.
Первое действие: Составить реестр существующих инструментов в репо (read-only).
