# 6V14-08: Реализовать heartbeat для всех активных процессов.
Статус: DRAFT_FOR_OWNER_APPROVAL (не принято, не done)
Цель: Реализовать heartbeat для всех активных процессов.
Цель размещения: репозиторий: nox-control/ [repo], /root/nox/state/ [server]
Доказательства: открытые PR нет; коммиты (упоминают ID) нет
Критерии приёмки:
1. Каждый активный процесс из реестра выдаёт heartbeat с меткой времени.
2. Процесс без heartbeat дольше порога помечается (порог задаёт владелец).
3. Heartbeat не останавливает и не перезапускает процесс.
4. Тест на моках проходит в repo; реальные процессы проверяет server probe.
Кто проверяет: repo-тест (п.1-4 на моках) / server probe (реальные PID)
Блокеры: Зависит от реестра 6V14-04 (по смыслу); цель включает /root/nox/state/ на сервере.
Первое действие: Модуль heartbeat + тест на моках в nox-control/.
