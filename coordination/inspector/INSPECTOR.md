# Инспектор NOX — один запуск, всё сразу

Запускается раз в час (отложенная задача) и вручную. Цель: NOX и Claude не стоят на месте. Правило владельца: при зависании сначала менять подход, владельца спрашивать только про деньги, доступ, удаление данных, снятие защит.

## Один запуск = 6 шагов
1. **Снимок.** Запустить `nox-control/c73/inspect.sh` через кнопку (`nox-control/cmd_agent/run_update.py`, REMOTE указывает на c73). Скрипт сам чинит безопасное (см. ниже) и печатает строку `DIGEST {...}`.
2. **История.** Дописать DIGEST и время в `coordination/inspector/HISTORY.jsonl` (PR в main). Сравнить с тремя прошлыми записями.
3. **Репо-сигнал.** `git log --since="1 hour ago"`: сколько коммитов по ID задач (`<ID>: ...`), открытых PR, что слито.
4. **Диагноз по лестнице.** Если за 3 запуска подряд ключевые числа (trainer, done, pending, blocked, коммиты) не изменились: переходить на следующую ступень, не повторять предыдущую.
   - A: прочитать лог глубже (хвост 200 строк, ошибки traceback), найти причину.
   - B: обходной путь (другая настройка, другой скрипт, малый батч, другая GPU, перезапуск сервиса из белого списка).
   - C: спросить советника/судью (nox-control/advisors) или суб-агента на дешёвой модели.
   - D: записать владельцу ОДНУ строку, только если нужны деньги, доступ, удаление данных или снятие защиты. Остальную работу не останавливать.
5. **Подсказки NOX.** Для задач, упавших 3 раза по одной причине, дописать в `coordination/inspector/HINTS_FOR_NOX.md` короткие нетехнические подсказки: «смени способ», «разбей задачу», «проверь зависимость», «спроси советника», «возьми задачу меньше».
6. **Отчёт.** 5 строк владельцу: что изменилось, что починено само, что сменили, что нужно от владельца (если нужно), когда следующий запуск.

## Чинить без вопросов (безопасно и обратимо)
- Запускать остановленные сервисы из белого списка: nox-train-keeper, nox-train-qwen9b-t131u, nox-agent-*, nox-dispatcher-t855u, nox-priority-scheduler, nox-self-learning-loop, nox-dialog-miner, nox-knowledge-index-t168u.
- Править свои скрипты c*/ и запускать через кнопку; делать бэкап `.bak_<id>` перед правкой файла на сервере.
- Менять параметры запуска обучения (батч, LR, GPU) без удаления данных.

## Только владелец
Деньги (аренда), доступ (ключи, пароли), удаление данных и моделей, снятие STOP/защит (STOP-флаг, pin volta HOLD_QWEN_REVISION_FILE_SHA, защита качества тренера), защищённые файлы V29.3, публикации наружу.

## Никогда
Не писать «жду владельца» дважды подряд об одной и той же причине без попытки другого подхода. Не считать «тронуто в коммитах» закрытием задачи.
