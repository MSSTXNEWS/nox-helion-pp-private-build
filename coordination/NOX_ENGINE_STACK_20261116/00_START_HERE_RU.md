# NOX — единый комплект обновления, 16 ноября 2026

## Открыть в первую очередь

1. `LAUNCH_QUEUE_RU.md` — полный состав, очередь запуска и настройки.
2. `NOX_24H_PROGRAM_RU.md` — программа первых суток и десять целей качества.
3. `system_runtime_profile.json` — параметры ресурсов и режимов, пока не активированные.
4. `maya_launch_profile.json` — аргументы основного движка, проверенные по исходному парсеру.
5. `training_profile.json`, `training_compatibility_notes.md`, `requirements-cp311-linux-cu126.lock` — отдельное окружение и обучение.
6. `core_hunter_integration.json` — единые S03, ядра, охотник и V28.

## Что означает готовность архива

Единый архив содержит фактически скачанные файлы, манифесты и программу применения. Полные веса учебного Qwen3.5-9B проверены; он не заменяет выбранную основную модель чата. Для основной DeepSeek-V4.1-Flash-1017 IQ2_XXS в комплекте пока есть точный манифест и первый metadata shard. Остальные 248 828 477 216 байт основной модели отсутствуют.

Статус скачанного набора: `DOWNLOADED_SET_WITHOUT_PRIMARY_WEIGHTS`. Архив не является автоматическим установщиком и не доказывает работающую новую модель. Все runtime-профили — кандидаты до нативной проверки. Epistemic LoRA для DeepSeek скачана для проверки; её автоприменение отключено.

## Приоритет

Сначала обучение, управление сервером, распределение ресурсов, память и охотник. Затем повышение эффективности ответов, самодописание и интерфейс. Один NOX, одна S03, один существующий диспетчер. Чат имеет приоритет по ресурсам. Платные API не нужны.
