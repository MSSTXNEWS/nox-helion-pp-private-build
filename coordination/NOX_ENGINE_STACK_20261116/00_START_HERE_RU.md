# NOX HELION — комплект подготовки новой модели
Версия 0.2 · 16 ноября 2026 · Linux x86_64 / Python 3.11 / 2×V100 32 GB

## Начать здесь
1. Откройте 02_program/NOX_24H_PROGRAM_RU.md: порядок первых суток, зависимости этапов и обязательный вывод старой модели из эксплуатации.
2. 02_program/wow_scorecard.json задаёт цель не менее 9/10 по каждому критерию. Все фактические оценки пока UNMEASURED.
3. 03_model_manifest/deepseek_iq2_xxs_manifest.json содержит точные публичные URL, revision, размеры и SHA256 выбранных весов.
4. 04_training содержит профиль QLoRA и семь проверенных wheel-пакетов; для полного окружения используется отдельный wheelhouse со своими manifest и hash lock; его фактический статус указывается отдельно.
5. 05_runtime_design содержит проект кэша и карту существующих S03/ядер/охотника. Исходники самого NOX остаются в частном GitHub репозитории по закреплённым ссылкам.
6. 06_evidence содержит фактические квитанции и проверенный журнал организации Drive.
7. 07_cuda12_build содержит пять проверенных компонентов CUDA 12.9.1 для сборки Maya. Это отдельный профиль от CUDA 12.6 для PyTorch.

## Что физически включено
- Шесть закреплённых архивов: Maya, Strata, standalone llama.cpp b11870, bnk, rclone, Prism Bonsai.
- Дополнительный точный llama.cpp commit 3cf03257f219afbe7334045ff7c6a06ac68c627d, который нужен для сборки Maya. Он отличается от standalone b11870 и не заменяет его.
- Семь wheel-пакетов: transformers, peft, trl, accelerate, bitsandbytes, datasets, safetensors. Каждый проверен по опубликованному PyPI SHA256.
- nvcc, cudart, CCCL, profiler API и NVTX из официального CUDA 12.9.1 redistrib, проверенные по официальному SHA256.
- Первый metadata GGUF shard DeepSeek IQ2_XXS, 5 780 704 байта, SHA256 проверен.
- Программа, профили, манифесты, источники исследований и журнал фактически выполненных операций.

## Что этот комплект ещё не означает
Полные веса DeepSeek: 248 834 257 920 байт. В этом ZIP находится только metadata shard; остальные GGUF не скачаны. Он не способен отвечать без остальных весов.
Исходники не являются собранными или установленными движками. У Maya v1.1.65 нет официальных готовых release binaries; нужна сборка sm70.
CUDA-компоненты не устанавливались и не исполнялись. cuBLAS указан в build manifest как отдельная потребность, которую следует сверить с имеющимися библиотеками.
Основной ZIP не является полным автономным Python-окружением. Для установки нужен отдельный resolved wheelhouse и hash lock; профиль кандидата не следует называть уже проверенной совместной средой.
Новая модель не переключена в чат, обучение новых весов не подтверждено, старые активные веса ещё не удалены.

## Обязательный итог переключения
Проверенный новый ответ через действующий NOX + S03 + инструменты → переключение чата → остановка старого serving-процесса → точное удаление его устаревших рабочих весов и ненужных адаптеров. Память, ядра, история, навыки и нужные учебные данные сохраняются.
Адаптеры 7B/35B другой базы не сливаются с DeepSeek по тензорам. Перенос полезного опыта выполняется через проверенные примеры и дистилляцию.

## Проверка комплектности
SHA256SUMS содержит хеш каждого файла, кроме самого SHA256SUMS. Проверка чтения ZIP и SHA256 выполнена при упаковке. Отдельные upstream manifest различают опубликованный хеш и локально вычисленный хеш архива.
