# NOX V16 · Краткое обязательное ТЗ

**Цель:** один рабочий Windows EXE NOX HELION. **Ручные:** №1 разработка+интеграция+сборка; №2 независимая E07-приёмка. **Авто:** 15 действующих, пять троек, каждый час :35/:45/:55/:05/:15 по Москве.

**7 направлений:** 1) исходный архив и 729 SHA; 2) остаток P01–P05 с D02/WOW/Persona; 3) один WPF/WebView2-host; 4) настоящий Windows CI; 5) NSIS+EXE+BuildID/SHA; 6) живые Ollama/SQLite/ModelCenter/RAG/GPU/голос/SPACE; 7) E07 10/10 на одном установленном EXE. **Это направления, не семь оставшихся TaskID.**

**Цикл:** 10 последовательных реальных подходов A1–A10; каждый имеет TaskID и результат. Команда пользователя `1` = один пакет C1–C5 в существующую очередь, `11` = два. Авто продолжают FIFO, не добавляют задания. DONE не переделывать. При блокере — другое полезное действие и точный HOLD.

**Отчёт каждого запуска:** RunID, фактическое начало/конец, A1–A10 DONE/PARTIAL/HOLD, было→стало, SHA+тесты, ошибки и следующий TaskID. **Ползунки:** 5 блоков P01–P05 + общий по весам 20/25/20/25/10; отдельно ход цикла и E07. Неподтверждённые проценты не выдумывать.
