# NOX HELION · ONEPASS (V25.1)

Этот пакет содержит настоящую последнюю собранную 10-страничную WEB-версию NOX, полный хэш-манифест 292 исходных файлов и скрипты для повторной проверки на физическом Windows-компьютере. **Это система исполнения и приёмки, а не обещание, что неизвестные функции уже написаны.**

## Один запуск на Windows

1. Распаковать ZIP в отдельную папку, например `C:\NOX_HELION\ONEPASS` (не поверх исходного работающего NOX).
2. Установить официальный Node.js 22+ при его отсутствии. Для физической проверки нужен Microsoft Edge и интерактивный Windows desktop с настоящей GPU. Никаких токенов в файл не вставлять.
3. Запустить `START_NOX_ONEPASS.cmd` двойным щелчком (или из PowerShell `& .\START_NOX_ONEPASS.cmd`).
4. Исполнитель проверит SHA всех 292 файлов, 10 маршрутов и оригинальные WOW ресурсы, запустит локальный тестовый сервер на случайном `127.0.0.1` порту, установит из npm Playwright в **свою** папку и проверит Chromium, затем Edge hardware. Это не меняет работающий NOX/Pod/production.
5. Он попытается **только локально** прочитать `/api/nox/status`, `/api/nox/training/status`, `/api/nox/progress` и S03 в уже запущенном OneHost по адресу `http://127.0.0.1:18775/`. Если OneHost не доступен, будет `HOLD`, а не фиктивный PASS.
6. Запрос на создание **одного тестового сообщения** в S03 по умолчанию отключён. В собственной изолированной тестовой сессии можно разрешить его перед запуском: `set NOX_ALLOW_TEST_CHAT=1` в `cmd`, или `$env:NOX_ALLOW_TEST_CHAT='1'` в PowerShell. Запись предварительно фиксируется как единственная — после ошибки никакого слепого дублирования POST.
7. Для *одной быстрой диагностики* без ожиданий: `$env:NOX_PREFLIGHT_ONLY='1'; node .\NOX_ONEPASS.mjs`. Для *одного полного цикла с выходом при HOLD*: `$env:NOX_ONCE='1'; node .\NOX_ONEPASS.mjs`.

## Результат и безопасная остановка

- `NOX_QA_RESULTS/FULL_ACCEPTANCE.json`: итоговая матрица и статус.
- `NOX_QA_RESULTS/state.json`: атомарное состояние, которое используется при перезапуске QA.
- `NOX_QA_RESULTS/chromium/report.json`: 7 размеров + 10 разделов + оригинальный V7 аудит.
- `NOX_QA_RESULTS/physical-gpu/qa-report.json`: физический Edge renderer и SHA всех скриншотов.
- `NOX_QA_RESULTS/onehost-proof.json`: реальные ответы существующего OneHost и подтверждения NOX, без копирования приватных ответов в отчёт.
- `NOX_QA_RESULTS/events.log`: происходившие этапы и ошибки.

Остановка: создать пустой файл **`NOX_STOP`** рядом с `START_NOX_ONEPASS.cmd`. Это остановит только исполнительский цикл QA на безопасной границе. Кнопка STOP работающего NOX и остановка GPU — **другой контур**: здесь они не вызываются, чтобы не прерывать вашу дистилляцию.

В отсутствие живого OneHost, выделенного тестового скоупа для общего STOP, подтверждённого восстановления S03, full-weight proof и физической авторской приёмки статус будет **HOLD** даже после полного зелёного Chromium. Чтобы получить полный релиз, автономный кодовый агент должен выполнить `NOX_AGENT_FULL_FINISH.md` на реальных исходниках и оборудовании, приложив доказательства.

Никаких общесистемных заданий автозапуска, перезапусков Windows/RunPod и удаления checkpoint пакет не создаёт.
