## Контроль каждого Astra запуска
1. Прочитать все 56 пунктов 01–56 из этого документа и сверить относящиеся к запуску задачи с реальными V15/V16 исходниками. Не заменять прочтение ссылкой или общими словами.
2. Прочитать новый delta главного журнала ошибок/мастер-журнала, C34 Error Journal и предыдущий урок самоулучшения.
3. Записать новые ошибки и статусы, один применённый урок, один краткий фактический отчёт в Google Docs, проверить обратным чтением каждый RunID. При невозможности записи сделать GitHub append-only fallback и честно отметить DRIVE_WRITE_HOLD.
4. Не считать 10×10 подходов подтверждением продуктового 100%; расчёт только по TaskID и фиксированному знаменателю с весами 20/25/20/25/10.
