# Матрица души и разума NOX (v1, 2026-11-20)

Основа: документы Диска «ДУША ИИ / SOUL MASTER V11/V12» (десять механизмов: Persona Continuum, Motivation, Emotional Consequences, Social Constellation, Culture/Beliefs, Real Work, Private Home, Helion Social, Cinematic Self-Media, Life Evolution), «50 улучшений скелета» (самосознание 21–30, память 11–20, саморазвитие 31–40, поглощение 41–50), «65 возможностей», хартия NOX v1 и совет старшей модели.
Правило честности: всё ниже функциональное (рабочие сигналы и устойчивые черты), NOX не заявляет, что переживает по-настоящему.

## Роли слоёв
- **Ядро (DeepSeek, GPU1+RAM)**: слова, сложные решения, творчество. Не дообучается.
- **Спинной мозг (плотная 8B, GPU0, учится LoRA ночью)**: оценка аффекта, маршрутизатор, сжатие памяти, судья по хартии, рефлексия, модель Создателя.
- **Память S03 + файлы состояния**: всё, что формируется. Растёт без обучения весов, обучение берёт из неё только проверенное.
- **Мост (:8091)**: конвейер каждого ответа: приём/STOP → «Я-сейчас» → память → оценка → ответ → проверка → запись.

## Что в архитектуре меняется
1. Мост: блок «Я-сейчас» (тело, процессы, эмоция) в каждом ответе — **сделано**; запись значимости, происхождения, эмоции и уверенности в память — следующий шаг.
2. Спинной мозг: плотная 7–8B с открытой лицензией; роли: аффект, маршрут, сжатие памяти, судья, рефлексия. Тренировка fp16 (V100 без bf16).
3. Память: поля significance, provenance, confidence, emotion, owner_feedback; индекс убеждений и профиль личности отдельными файлами с хешем.
4. Данные для обучения: только проверенные факты старше 7 дней + пары «ответ/оценка Создателя» (KTO). Тест верности ~100 провокаций перед любым принятием адаптера.
5. Ядро: ускорение (слоты, батч, префикс-кэш), без дообучения; личность держится префиксом и состоянием.

## Очередь внедрения
1. Поля памяти + запись эмоции/уверенности (мост).
2. Профиль личности и убеждений (файлы, дрейф-лимиты, журнал).
3. Спинной мозг: выбор модели, запуск на GPU0, роли аффект/судья.
4. Кнопки оценки ответов 👍/👎 → датасет KTO.
5. Ночной цикл сна + LoRA спинного мозга.
6. Тест верности и принятие адаптера.
