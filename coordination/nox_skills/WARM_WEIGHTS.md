# Навык NOX: тёплые веса и бэкапы на ПК владельца

ПК владельца хранит холодные веса (`NOX\MODELS`) и бэкапы (`NOX\BACKUPS`). Канал: ПК открывает обратный SSH-туннель к серверу (файл `PCLINK_START.cmd`), на сервере ПК виден как `http://127.0.0.1:18765`. Ключ туннеля ограничен: только этот порт, без оболочки.

## Инструмент `warm_weights` (selftools)
1. `status` — есть ли канал (`pc_link`), сколько RAM свободно (`/dev/shm`, сейчас ~47 ГБ), что уже загружено.
2. `list` с `path` (например `llm`) — что лежит на ПК.
3. `pull` с `path`: сначала dry-run (по умолчанию), потом `dry_run:false`. Докачка при обрыве автоматическая (Range). Файл попадает в `/dev/shm/nox_warm/` (RAM, диск не занимается).
4. Загрузка в модель: путь `/dev/shm/nox_warm/<файл>` передать как `-m` llama-серверу помощника (учитель/дистилляция) через `svc_ctl`; основная модель DeepSeek не трогается.
5. `evict` — выгрузить файл из RAM, когда он не нужен (RAM нужна чату и обучению).
6. `backup_push` — отправить готовый файл из `/root/nox/...` на ПК. Для полного бэкапа: `bash nox-control/pc_warm/make_backup.sh`.

## Правила
- Нет канала → `blocked`: не повторять в цикле, сообщить владельцу «нужен запуск PCLINK_START.cmd».
- Чат важнее: перед `pull` проверить `status.free_gb` и оставить ≥ 4 ГБ запаса.
- Скачивание новых моделей на ПК делает владелец через `download_models.ps1` (Qwen3-30B-A3B Q4_K_M, FLUX, SDXL, ComfyUI, видео, музыка); NOX их только читает.
- Всё пишется в аудит-лог selftools.
