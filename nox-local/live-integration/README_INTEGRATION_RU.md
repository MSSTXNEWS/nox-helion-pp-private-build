# NOX LOCAL LIVE INTEGRATION · candidate 01

**Источник:** NOX_READY_INTEGRATION_01.zip + готовые Tabler/Three.js/ECharts и существующие API.

## Готовые части

- 9 маршрутов NOX: HOME, CHAT, TRAINING, MODELS, MEMORY, SYSTEM, INSTALL, PROJECTS, SETTINGS. Для новых разделов использованы существующие файлы Tabler, без второй базы и без отдельного AI runtime.
- Живой `/api/status`, локальный Ollama streaming, серверный STOP из исходного проверенного моста.
- Один Cinema HUD ECharts; дублирующий прежний приборный блок исключён на HOME/CHAT.
- Web Push-кнопка запрашивает разрешение только по клику и показывает HOLD без проверенных ключей и отправителя.
- Read-only обнаружение существующих SQLite/S03, training logs/checkpoints и модели через текущий Ollama.
- Модель можно выбрать из страницы MODELS и перейти в чат.
- Настройки MAX/BALANCED/ECO как сохранённое предпочтение; перенос на драйвер рендерера должен быть проверен отдельно.

## Неподтверждённые / HOLD

- В исходниках нет проверенного контракта запуска существующего LoRA/QLoRA-тренера: START/PAUSE/RESUME/ROLLBACK не будут выдавать фальшивый успех.
- Физическое чтение/запись SQLite/S03 не разрешено по одному факту нахождения файла. Нужны действующие схема, API и проверка без потери данных.
- 18 моделей ранее были восстановлены пользователем, однако текущее точное число определяется только через `/api/tags`.
- Доставка Web Push при закрытом браузере не подтверждена; без VAPID и работающего сервера оставлена HOLD.
- Точные GPU/VRAM/температуры у AMD Radeon 660M зависят от реальных источников; отсутствие показаний = Н/Д.
- Новая реальная сцена Eclipse Sun, точно соответствующая утверждённому изображению, не найдена в проверенных исходниках. Сохраняется оригинальная готовая Black Hole-сцена из предыдущего манифеста. Новая картинка не подменяет WebGL.
- В контейнере Chromium блокирует loopback (`ERR_BLOCKED_BY_ADMINISTRATOR`), Windows browser QA не подтверждена.

## Сохранность

Команда установки создаёт **одну** папку `C:\NOX_HELION\APP\NOX_WEB\_INTEGRATION_CANDIDATE`, копируя текущие исходники. Она не останавливает Ollama, не пишет в S03/веса, не удаляет старые версии, не включает автозапуск. После локальных тестов запускается отдельный порт 18775. Для замены текущего порта 18774 необходима отдельная физическая приёмка и подтверждённое безопасное переключение.

## Приёмка

`python -m unittest -v test_integrated` — локальные HTTP contract tests. Остальные 11 тестов базового пакета выполняются по `python -m unittest discover -s tests -p 'test_*.py' -v` с одним пропущенным браузерным тестом. Тесты не заменяют Windows visual acceptance.
