# Исполняемое ядро NOX · 800 операций и собственная сеть 10K

В редакции для CORE один основной процесс GLM и одно пространство диалога. Патч встраивает обработку в штатный POST /v1/chat/completions после STOP. Вычисляемые действия работают на CPU со стандартной библиотекой Python. Для нейросетевого подбора и обучения нужен NumPy. Веса для старта уже входят в сборку: brain800/router10k.npz. Личные примеры в поставляемых весах отсутствуют.

## Как наблюдать рост

В именованной беседе напишите «Запомни замысел: в начале сцены оставляем паузу», затем «Покажи замыслы». Запись переживает перезапуск. «Продолжи замысел: паузу» возвращает найденную запись в обычную модельную ветку. Память этой версии локальна для идентификатора беседы. Имена и личные подробности остаются в хранилище проекта; текущий мост использует отдельный SQLite рядом с S03.

Откройте «мастерскую навыков» фразой «Открой мастерскую навыков». В ней ядро замечает две подряд операции, у которых результат первой действительно был передан в одно поле второй. Оценка «Это помогло» даёт наблюдению основание. Когда на другом исходном материале такая же связь повторилась и пользователь одобрил результат, NOX сам выбирает пару, поле связи, присваивает имя навыку и регистрирует его версию. Исходные примеры нужны только для двух последних шагов мастерской. После закрытия мастерской эти данные очищаются; версии навыка и отпечатки подтверждений сохраняются. «Чему ты научился?» открывает собственные навыки. Команда /brain apply принимает JSON с name, a и b. Команда /brain revoke с name позволяет отозвать навык.

После обычного хода ядро прогнозирует, получится ли технически завершить ответ без деградации, сверяет прогноз с фактом и корректирует ожидания по области диалога. Из наблюдаемого сбоя, отвергнутой инициативы и расхождения прогноза с исходом возникает собственная цель. «Над чем ты работаешь?» показывает её и основание; «Как ты изменился?» возвращает историю изменений. Любопытство, осторожность, уверенность и инициатива регулируют дальнейшее поведение. Когда вы говорите «Это не помогло», оценка относится к конкретному решению в данной беседе. При сдержанном режиме CORE пропускает вступление. В других режимах может предложить вариант или попросить конкретное уточнение. Эти состояния — вычислимые регуляторы, а техническое завершение ответа само по себе не доказывает его правильности.

## Что означает 10 000

119 чисел кодируют запрос и структуру аргументов. Десять скрытых компонент обучаются совместно, на выходе 800 оценок зарегистрированных действий. Матрица входа содержит 1 190 весов, первый слой имеет 10 смещений, выходная матрица — 8 000 весов, последний слой — 800 смещений. Каждый адрес параметра уникален. Некоторые входы коррелируют, при хешировании возможны коллизии. Ширина 10 ограничивает размерность внутренних представлений. Восемь прикладных модулей в реестре не переименовывают восемь органов канона.

Первичная модель обучена на 800 описаниях операций с признаками их аргументов и 52 редакторских синтетических примерах. Все 119 колонок активировались хотя бы раз. На 13 отдельных синтетических задачах верный выбор оказался первым в 5 случаях, в первой пятёрке — в 13. Эту же выборку использовали при разработке. Это внутреннее измерение с ограниченным охватом. Поэтому команда «/brain подбери …» предлагает пять вариантов и не запускает выбранную моделью операцию. Проверенные прямые команды работают независимо от качества прогноза.

При обучении LoRA ранга 4 для выходного слоя дополнительно обучаются 3 240 коэффициентов A/B. Изменения можно слить математически в исходную форму 10K. Отдельный эксперимент с локальной LoRA не улучшил 5/13, поэтому в стартовом профиле активна базовая сеть. Команда /brain teach принимает явно отобранную запись {text, data, op, group, consent}. После восьми независимых групп ядро самостоятельно обучает кандидата, сравнивает его с действующей версией и закрепляет в текущей области только при улучшении без регрессии по условиям evolve.py. Кандидат хранится отдельно. Через python -m brain800.evolve доступны status и rollback. Обычные разговоры не становятся учебным корпусом по умолчанию. Смена весов основной GLM требует отдельного совместимого обучаемого основания; модуль adapter_export подготавливает согласованные обезличенные пары, проверяет манифест и адаптер. GGUF запущенной GLM не модифицируется.

## Запуск и подключение

Готовый канон содержит встроенный пакет nox_wow/BRAIN/brain800. Для другой копии GitHub-дерева используйте install_core.py рядом с core800.patch: python install_core.py --repo /path/to/nox. Обратное действие — тот же вызов с --undo. Скрипт проверяет состояние целевых путей и применимость патча. Для изменения на работающем сервере нужен обычный выпуск сервиса CORE. Патч и установщик не управляют арендой или питанием S1. NOX_BRAIN800=0 отключает новый маршрут в CORE.

При вызове чата используйте отдельный nox_conversation_id. Право на эту беседу должно проверяться внешним владельческим шлюзом, идентификатор сам по себе не аутентифицирует пользователя. Параметр NOX_STATE указывает каталог данных. Локальная проверка всего ядра: из дерева пакета python ../../BRAIN800_PATCH/verify_core.py .. при текущем каталоге nox_wow/BRAIN/brain800. Полный пример для любых абсолютных путей: python /path/to/nox_wow/BRAIN800_PATCH/probe_native.py /path/to/nox_wow/BRAIN.

Примеры работающих входов:

- «Упорядочи задачи: запись → монтаж → выпуск; титры → выпуск».
- «Сравни варианты по баллам: веса: качество=2, время=1; утро: качество=5, время=2; вечер: качество=3, время=4».
- «/brain studio.pause.duration {"scene":{"pause":[{"id":"p","start":150,"end":500}]}}» возвращает 350 мс.
- «/brain find паузы» находит операции; /brain ID с JSON выполняет выбранную операцию. Новые составные навыки хранятся поверх 800 встроенных.

Серверные частоты CPU, GPU и памяти не требуются для этих функций. Физический запуск редакции на S1 и обучение большой GLM этим выпуском не подтверждены.
