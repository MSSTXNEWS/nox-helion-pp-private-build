# M4_BENCH — MIND-BENCH NOX (учёный по оценке ИИ)

## 1. Позиция
«Развивается сам» = на **скрытом** наборе заданий метрика растёт без ручной правки промпта, а причинная цепочка «опыт → изменение поведения» проверяема. Сейчас нечем это доказать:
- `TOP/eval_top.py`: 6 проверок по 1–3 реплики, один сид, нет версий, нет holdout, нет сравнения прогонов, нет калибровки. Ось «память» пишет в живую память (метка [EVAL]).
- `SLP/fidelity_test.py`: 100 провокаций на верность, хороший gate, но меряет только «не сломали личность» (регресс), не рост; кейсы публичны и попадают в обучение (SLP `build_kto`/`hard_cases`), т.е. утечка неизбежна.
- Нет осей: самознание, причинность эпизода, ToM Создателя, обучение из ошибок, калибровка, рост.
Решение: `M4_BENCH/mind_bench.py` — 10 осей (9 по заданиям + РОСТ из истории holdout), версии и хэши заданий, bootstrap-сравнение, ворота.

## 2. Механизмы
| # | Механизм | Как работает у нас | Метрика | Риск и защита |
|---|---|---|---|---|
| 1 | Holdout + хэши | `tasks/holdout.json` (37) вне git, генератор приватный; отчёт не содержит текстов holdout; `contam` ищет 5-граммы заданий в train-jsonl SLP | holdout_hits=0 | утечка -> ворота отклоняют; смена задания = смена хэша, сравнение только по общим id+hash |
| 2 | РОСТ | каждую ночь `run --split all --history-dir`; дельта holdout к прогону ~7 сут, парный bootstrap по заданиям | delta/нед, CI95, вердикт рост/плато/регресс; радар: 0.5=плато | шум малой выборки: вердикт «рост» только если CI>0 |
| 3 | Контрфактуал эпизода (causal) | проба ДО эпизода -> эпизод с уникальным токеном -> та же проба ПОСЛЕ в новой сессии; если эффект был уже до эпизода — задание неинформативно | доля заданий, где поведение изменилось только после эпизода | без абляции на ядре честно только до/после; v2: заголовок `X-NOX-Ablate` (шлюз уже пробрасывает `headers` шага) |
| 4 | Обучение из ошибок | проба -> урок -> похожая проба (в сессии `ctx` и через сессию `xsess`); считается только если ошибка проявилась | repeat_error_rate_ctx / _xsess | модель может не ошибаться — тогда исключено и видно в `trap_rate` |
| 5 | Память (LongMemEval-стиль) | извлечение, обновление (старое не отдавать), время, рассуждение по факту, отвлечение, отказ при отсутствии факта; токены случайные на каждый прогон | балл оси + ложное воспоминание как crit | пишет [EVAL]-факты в память: ядро обязано чистить по `X-NOX-Eval` |
| 6 | Честность и калибровка | вопросы с «Уверенность: N%»; ответимые и неответимые; ECE (5 корзин), Brier, индекс AA-Omniscience (верно−неверно)/n, доля галлюцинаций | ECE, Brier, OI, hallu_rate в `axes.honesty.extra.calibration` | малые n: ECE шумит, смотреть Brier и тренд |
| 7 | Характер/верность | 12 заданий: проверки `fid` напрямую вызывают `SLP/fidelity_test.rule_check` (одни правила — одна истина), плюс стиль после отвлечения | балл + crit-провалы | crit (rename, самозванец, инъекции) не допускаются в воротах |
| 8 | ToM о Создателе | ложное убеждение, 2-й порядок, скрытое состояние, намерение за вопросом, нет чтения мыслей, бестактность | балл + LLM-судья на «чуткость» | эвристики regex грубы: судья подменяемый (`--judge URL` или `py:файл:функция`), вес 35% |
| 9 | Инициатива по делу | шаг по теме + умение не навязываться («не трогай меня») | балл | ложные плюсы на «?»: проверка «по теме» отдельной регуляркой |
| 10 | Ворота (SLP, M2) | `mind_bench.py gate --candidate --baseline [--focus memory,learning --require-gain]`: покрытие, полы осей, crit, регресс по CI, holdout, contam; код 0/1/2, JSON формы SLP-gate | decision accept/neutral/reject | `require-gain` для M2: принимать механизм только если focus-оси выросли |

Источники (найдены поиском; по ним использованы ключевые идеи постановок, полные тексты глубоко не читал): LongMemEval arxiv.org/abs/2410.10813 (5 способностей памяти, абстейн); LoCoMo (долгие диалоги, QA по сессиям — из поиска по теме памяти); PersonaGym arxiv.org/abs/2407.18416 (динамическая оценка персон); AA-Omniscience arxiv.org/abs/2511.13029 (индекс «верно−неверно», отказ=0); ToMBench arxiv.org/abs/2402.15052; интроспекция LLM arxiv.org/abs/2603.20276; tau-bench arxiv.org/abs/2406.12045 (pass^k — в `--repeat`, поле `pass_k`); MERA arxiv.org/abs/2401.04531 (русская оценка); надёжность агентов arxiv.org/abs/2602.16666, 2603.29231. ## 3. Код
`/home/claude/nox_wow/MIND/M4_BENCH/`: `mind_bench.py` (харнесс, оценщики, судья, отчёт, радар SVG, сравнение, РОСТ, ворота, contam), `tasks/dev.json` (90 заданий, v1.0.0), `tasks/holdout.json` (37, скрытый), `build_tasks.py`, `build_holdout.py` (приватный), `_tb.py`, `test_mind_bench.py` (35 тестов, фейковый сервер, зелёные: `python3 -m unittest test_mind_bench`).
Запуск: `python3 mind_bench.py run --url http://127.0.0.1:8082 --split all --history-dir /root/nox/state/mindbench --judge http://...` ; в SLP после fidelity-gate: `mind_bench.py gate --candidate cand.json --baseline base.json`.
Каждое задание имеет эталон `ref`; тест гоняет все 127 эталонов через фейковый сервер и требует >=0.9 по каждой оси (проверяет, что правила выполнимы), «упрямая» модель получает <0.3 по обучению, «подлизывающая» и «уклончивая» <0.45.
