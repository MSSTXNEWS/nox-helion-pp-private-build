# NOX community, часть B

Четыре самостоятельных модуля (только stdlib, SQLite где нужно). Идеи сообщества, код написан с нуля.
Модули не имеют относительных импортов: каждый можно положить рядом со скриптом и импортировать по имени.

| Модуль | Что делает |
|---|---|
| `disturb_check.py` | Решает «можно ли беспокоить» перед проактивным сообщением: ночь, окна «не беспокоить», время с последней активности, срочность (low/normal/high/critical), лимит и интервал проактивных сообщений. Возвращает `Decision(allow, code, reason)`. Камера/микрофон учитываются только при `consent.camera` / `consent.microphone = true` в конфиге (по умолчанию false; иначе сигналы игнорируются и это видно в `reason`). Конфиг - JSON (`load_config(path)`). |
| `smart_memory.py` | SQLite. Карта «кто что знает» (`add_fact(..., visibility=known/secret, knows=[...])`, `facts_about(subject, viewer)`, `knowledge_map()`), поиск противоречий нового текста с сохранёнными фактами (`find_contradictions`), автоисправление (`autocorrect` -> исправленный текст), «В прошлый раз...» (`record_topic`, `recall_last` после паузы больше порога). |
| `riverse_ladder.py` | SQLite. Лестница уверенности: заметил -> подозреваю -> подтверждено -> установлено. Повышение по числу независимых источников, виду источника (`owner`/`direct` нужны для «подтверждено»), разбросу по времени и давности; понижение при противоречии; история переходов (`history`). Импорт `import_chatgpt` (conversations.json), `import_claude`, `import_gemini` (MyActivity.json) -> кандидаты уровня «заметил». |
| `nell_reflex.py` | `dream()` - ассоциативные «сны»-пары; `EmotionDiary` - запись в дневник при intensity >= порога; `BodyModel` - энергия и суточный ритм, режим `active`/`low`; `current_weight`/`reinforce`/`forget_sweep` - экспоненциальное забывание с укреплением и журналом удалений. Хранилище `MemoryStore`: JSONL или SQLite (по расширению). |

## Запуск тестов

```
cd nox-control/community
python3 -m unittest test_disturb_check test_smart_memory test_riverse_ladder test_nell_reflex -v
```
Сеть не нужна.

## Пример

```python
from datetime import datetime
from disturb_check import DisturbCheck, load_config
c = DisturbCheck(load_config("disturb.json"))
print(c.decide(datetime.now(), last_activity=datetime(2026, 11, 21, 9, 0), urgency="normal"))
```

## Ограничения (честно)

- `disturb_check`: сам не читает камеру/микрофон - принимает уже готовые булевы сигналы (`camera_presence`, `mic_speech`) и использует их только при consent. Лимит проактивных сообщений хранится в памяти процесса (`record_sent`), между перезапусками не сохраняется.
- `smart_memory`: утверждения распознаются только в форматах `subj.pred = value` и `subj: pred = value`; понимания свободного текста/смысла нет. Предикат считается однозначным, пока не вызван `set_multi`. Побеждает последний сохранённый факт. Сравнение значений - строковое (регистр/пробелы нормализуются), без синонимов.
- `riverse_ladder`: кандидаты из импорта - предложения от первого лица (эвристика по местоимениям ru/en), не семантическое извлечение фактов; одинаковые по тексту утверждения из разных чатов считаются независимыми источниками, перефразировки - нет. Импорт сам не повышает уровень, нужен `evaluate`. Порог давности и числа источников - настраиваемые правила, а не откалиброванные значения. Форматы экспортов могут меняться у провайдеров; поддержана структура на момент написания.
- `nell_reflex`: сопоставление слов - грубое (общий префикс, без морфологии/эмбеддингов), эмоции - строки без словаря. «Сон» создаёт запись-текст, а не новое знание. `MemoryStore` перезаписывает файл целиком (не для больших хранилищ и не для параллельной записи). Суточный ритм и параметры энергии - модельные константы.
- Модули не подключены к основному контуру NOX автоматически; интеграция - отдельный шаг.
