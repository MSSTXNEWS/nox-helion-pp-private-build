# nox-planets

Фото-текстуры планет — Solar System Scope (https://www.solarsystemscope.com/textures/), основаны на данных NASA, лицензия CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Авторство: «Solar System Scope».

- `nox-mercury.jpg`, `nox-venus.jpg`, `nox-earth.jpg`, `nox-mars.jpg`, `nox-jupiter.jpg`, `nox-saturn.jpg`, `nox-uranus.jpg`, `nox-neptune.jpg` — одобренные текстуры 2048x1024 из сборки (assets/nox-approved/planets, с Диска), перекодированы в progressive JPEG (качество 84) без изменения размера; других правок нет.
- `2k_moon.jpg` / `moon.jpg`, `2k_earth_daymap.jpg` / `earth_daymap.jpg` — Луна и прежние уменьшенные копии (зеркало homer-jay/solar-system-textures, README зеркала указывает источник и лицензию).
- Кольца Сатурна: файла нет, рисуются процедурно (в статусе настроек отмечено `ring:procedural`).
- Процедурная текстура включается только если файла нет или он не открылся; статус каждой планеты виден в Настройках («ТЕКСТУРА: <файл>» либо «процедурная»).
