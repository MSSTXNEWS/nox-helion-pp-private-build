# DRIVE_IDEAS_T — идеи и требования из протоколов и ТЗ Диска (аудит, часть 3, 2026-11-25)

Формат: одна идея или требование на строку, в конце источник. Метки: [ЧЕРВИ], [NEXUS], [ГЕНЕРАЦИЯ ИДЕЙ], [КОНТЕНТ], [РИСК], [ОПЕР] (эксплуатация сервера, не продукт).
Сокращения источников: ПРОТ = Протокол 24.11 (1d8b…); КАН4 = КАНОН v4 OWNER-FIRST (1avU…); МАКС = МАКСИМАЛЬНАЯ ЗАГРУЗКА ГОТОВОГО (1uyT…); ИНСТР7 = ИНСТРУКЦИЯ ИСПОЛНИТЕЛЮ v7 (1Q6E…); НАЧ = 00_НАЧАТЬ_ЗДЕСЬ (1GAJ…); ПОЛН = Полный список требований (17Dj…); Q295 = очередь 295 (1V5H…, ЧАСТИЧНО); REG = реестр NOX-2 (1CDQ…, ЧАСТИЧНО).

## Черви, провайдеры, поглощение

- [ЧЕРВИ] На каждом сервере постоянно живёт червь-диспетчер: каждую минуту смотрит GPU, VRAM, RAM, CPU, диск и приоритеты, дозаправляет простой, пишет журнал. (ПРОТ, решение t1144u)
- [ЧЕРВИ] Пять управителей на общей базе: Переосмыслитель, Пастух червей, Управитель обучения, Управитель тела, Садовник памяти. (КАН4 §4.1)
- [ЧЕРВИ] Охота за знаниями только с вопросом «разрешаешь?»; червь соблюдает STOP до и после запроса, квоты, HTTPS и белый список. (КАН4 §7.5)
- [ЧЕРВИ] Голод: нет проверенного поглощения больше 1 ч → «Создатель, мне нужны данные»; очень голодный — после 24 ч. (КАН4 §7.5)
- [ЧЕРВИ] Поглощение: скачать → учитель в слот генерирует данные по теме → судьи отбирают → NOX учится → вывод учителя из эксплуатации после ворот. (КАН4 §9.1, §13 п.26)
- [ЧЕРВИ] Загрузчик nox-dlq: 20 воркеров, проверка лицензии и признаков Claude перед каждой загрузкой, работа только при ОЗУ от 8 ГБ и диске от 12 ГБ. (ПРОТ §8.4)
- [ЧЕРВИ] Территория: свои веса, S03 append-only, born_at неизменяем; доминирование только на воротах качества. (КАН4 §7.5)
- [ЧЕРВИ] Три учителя поглощения: 9B, 27B, 32B; SHA жертвы; удаление учителя после; дедупликация; проверка происхождения. (ПОЛН §5)
- [ЧЕРВИ] Пункт «доминирование при конфликте» и «защита весов (территория)» — требования ПОЛН §5 не имеют отдельной механики в КАН4. (ПОЛН §5)
- [ЧЕРВИ] Контракт диспетчера: PID, start_ticks, heartbeat меньше 90 с, writer lease; при нарушении HOLD. (КАН4 решение 4.3)
- [ЧЕРВИ] Флаг STOP-файл и тишина: рестарт ядра только после 180 с тишины владельца и без lock-файла обучения. (ПРОТ §0, §6.2) [ОПЕР]

## NEXUS (провайдеры, маршруты, доступы, квоты)

- [NEXUS] Права по уровням: read, suggest, draft, execute, publish, pay, admin; cost caps и spend approvals; просьба персонажа права не повышает. (КАН4 §2.1 п.12)
- [NEXUS] Бесплатные модели через litellm-роутер; ключи только у владельца, бюджет 0. (ПРОТ §4.5)
- [NEXUS] API-шлюз для внешних ИИ (Bearer), доступ по токену из secrets; перевыпуск токена — только владелец. (ПРОТ §3, §4.4) [РИСК: не печатать значения]
- [NEXUS] Советники: только бесплатные и ручной мост (человек переносит запрос и ответ); без скрапинга. (КАН4 решение 16, §8.3)
- [NEXUS] Внешние советники получают только обезличенный минимум; класс «иск, суд, финансы, здоровье» наружу не уходит никогда. (КАН4 §2.2, решение 11.2)
- [NEXUS] Деньги: всё по карточке, позже виртуальная карта с суточным лимитом; GitHub — запись только в ветки и PR. (КАН4 §2.2)
- [NEXUS] Реестр моделей: PROPOSED → FETCHED → VERIFIED → ACTIVE_ADAPTER → TRAINING → ABSORBED → REMOVED; один active_model_id на роль. (КАН4 §4.1)
- [NEXUS] Сеть и туннели: новые публичные туннели и порты только по слову владельца. (ПРОТ §0.3)
- [NEXUS] Права Димы (второго пользователя): читать и писать свою память, ставить задачи без денег, удаления и FORGE; при сомнении спросить, кто пишет. (КАН4 §6.3, решение 6.4)
- [NEXUS] Биометрия (лицо, отпечаток, голос) выключена до отдельного слова владельца. (ПРОТ §2.1, КАН4 решение 19)

## Генерация идей

- [ГЕНЕРАЦИЯ ИДЕЙ] Конвейер «с душой» для крупных задач: улучшить идею → поиск → совет → оценка по рубрике → выполнение → экзамен. (КАН4 §8.1)
- [ГЕНЕРАЦИЯ ИДЕЙ] Научная лаборатория: реестр гипотез (формулировка, предсказание, способ опровержения), черви тянут первоисточники. (КАН4 §8.1)
- [ГЕНЕРАЦИЯ ИДЕЙ] NOX сам предлагает себе задачу; «неделя: смотри, что изменилось». (КАН4 §9.2)
- [ГЕНЕРАЦИЯ ИДЕЙ] Сны REM как гипотезы; ночь: сбор дня, рефлексия, отбор, обучение, replay, самооптимизация, утренний отчёт. (КАН4 §9.1–9.2)
- [ГЕНЕРАЦИЯ ИДЕЙ] Контрфактический двойник раз в неделю: компонент выключен, ответ сравнивается — доказательство причинного вклада. (КАН4 §4.2)
- [ГЕНЕРАЦИЯ ИДЕЙ] Outlooks и параллельные «я» с ветками и слиянием — вау-слой очереди 3–4 после ворот. (КАН4 решение 8.3)
- [ГЕНЕРАЦИЯ ИДЕЙ] Идеи владельца I-01…I-89 и CI-04…CI-17 (идеи сообщества, переименованы, чтобы не путать с C01–C08). (КАН4 §4.2, §8.1)
- [ГЕНЕРАЦИЯ ИДЕЙ] Пожелание владельца: «добавляй не ухудшая» — правило для всех новых идей. (ПРОТ §0, КАН4)
- [ГЕНЕРАЦИЯ ИДЕЙ] Лента споров внутренних ролей («закулисье»), равная журналу конфликтов. (КАН4 §7.6)

## Обучение и ворота

- [ОПЕР] Ворота адаптера: верность не меньше 0,85 абсолютной планки; относительное «+0,03 к лучшему» отклонено. (ПРОТ §2.1, §3.2)
- [ОПЕР] Ворота капсулы раз в неделю: душа не ниже 0,90 плюс 17 критических кейсов; ядро не ниже 0,85; отставание от донора не больше 10%. (КАН4 §9.1)
- [ОПЕР] Замороженный holdout (344 строки) не подменять от раунда к раунду; ранний стоп min_step 150, patience 3. (ПРОТ §3.2)
- [ОПЕР] Двойной судья разных семейств; судья не судит свои ответы; спор уходит в gold_disputes. (ПРОТ §3.2)
- [ОПЕР] Семь видов обучения, которые страница обязана различать; честный статус «что реально изменилось». (КАН4 §9.1, §9.3)
- [ОПЕР] Четыре независимые шкалы роста: игровая, память, проверяемая квалификация, версии весов. (КАН4 §9.1)
- [ОПЕР] WEIGHTS LAB: SHA адаптера, reload, rollback при NO_GAIN, реестр экспериментов. (КАН4 §9.1)
- [ОПЕР] Model Center: каталог с лицензией, VRAM и источником; pinned download в staging с SHA, без автоподстановки. (КАН4 §9.1)
- [ОПЕР] Метрики непрерывного обучения BWT и FWT: забывание не больше 2 п.п., перенос не меньше 0. (КАН4 §9.2)
- [ОПЕР] Бенчмарки памяти: LongMemEval и LoCoMo не меньше 70%, отказ не меньше 90%; ложное «помню» не больше 2%. (КАН4 §6.2)
- [ОПЕР] Ловушки ToM: ToMi, BigToM, Hi-ToM, FANToM, OpenToM; индикаторы сознания Butlin (14 штук). (КАН4 §8.2)
- [ОПЕР] Экзамен живости: 40 вау-сцен как приёмочный набор; балл живости по 13 главам. (КАН4 §8.2, §12.2; МАКС §7)
