# ICONS_REFS (TH): иконки, кнопки, движки UI

Статус: раздел «Движки UI» (предварительная оценка по документации, без визуального сравнения на наших страницах). Референсы по 10 продуктам и сравнение наборов иконок: пакет 2 (не сделано).

## Движки UI
| Кандидат | Лицензия | Что даёт | Под наш стек (vanilla + sl-*) |
|---|---|---|---|
| Web Awesome 3 (наследник Shoelace, та же команда) | бесплатное ядро (проверить лицензию пакета перед установкой), есть pro-часть | button, dropdown/menu с подменю, drawer, tabs, wa-stack/wa-cluster, встроенные темы | самый прямой путь: тот же API, переименование sl-* в wa-* (есть migration checklist). Минус: массовая замена тегов на 77+ страницах и вес бандла, нужна проверка |
| Basecoat (hunvreus/basecoat) | MIT | дизайн shadcn/ui на ванильном HTML, малый JS; CDN-обёртка CSS | стиль Linear/Vercel, но это классы, а не компоненты sl-*: нужен CSS-мост; npm-путь использует Tailwind. Сайдбар, кнопки, меню есть (состав подтверждать на basecoatui.com) |
| Ionic Web Components | MIT | мобильная навигация, tab bar, переходы | только для мобильной навигации (390), на десктопе не нужен |
| ninja-keys | MIT | командная палитра | уже в vendor |

Решение на сейчас: пакет gr1 уже даёт «CSS-мост» поверх sl-* (токены Shoelace + .nx-btn) в стиле Linear/Vercel без переписи страниц. Топ-1 для десктопа: Web Awesome 3 (минимальный риск миграции, одна экосистема); Basecoat как источник готовых стилей кнопок/меню; Ionic только для мобильной навигации, если дока gr1 на 390 не хватит. Перед установкой: проверить лицензию и вес бандла WA 3, пробный стенд на chat/index/settings (снимки 1440 и 390).
