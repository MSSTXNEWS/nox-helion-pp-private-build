# PHOTOREAL100: 100 настроек и анти-настроек для фотореализма (живое, люди)

Источники: stable-diffusion-art.com/realistic-people, openart.ai guide to SD parameters, machinelearningmastery.com generate-realistic-faces, практики ADetailer/ControlNet. Значения ориентировочные, подбирать под модель.

**Ограничения:** никаких изображений несовершеннолетних в фотореалистичном или сексуальном контексте; никаких фото реальных людей без их согласия; пресеты нейтральные. Пока /img/generate выключен, пресеты передаются текстом в промпт vision-модели.

## Модель и сэмплер
1. Чекпоинт, обученный на фото (не аниме/арт), основа realism
2. Chroma/Flux-класс для естественной кожи; SDXL как запасной
3. Сэмплер DPM++ 2M Karras: стабильные детали
4. Сэмплер Euler a для мягких портретов
5. Сэмплер DPM++ SDE Karras: больше микродеталей
6. Шаги 25-35 (больше 40 почти не даёт)
7. Шаги 20-28 для Flux/Chroma
8. CFG 4-7 для SDXL (выше 9 даёт пластик и пересвет)
9. CFG 1-4 / guidance 3-4 для Flux-подобных
10. Фиксируемый seed для сравнения вариантов
11. Пакет 4 seed и выбор лучшего
12. Scheduler Karras/ SGM uniform по модели
13. VAE: родной, не подменять без нужды
14. Clip skip 1 для фото-моделей
15. Не смешивать больше 2 LoRA с суммарным весом выше 1.2

## Разрешение и апскейл
16. База 1024x1024 для SDXL, 832x1216 портрет
17. Кратность 8 (лучше 64) сторон
18. Не превышать нативное разрешение модели в первом проходе
19. Hires fix: апскейл 1.5x
20. Hires denoise 0.3-0.45
21. Апскейлер 4x-UltraSharp/ESRGAN для фото
22. Тайловый апскейл (Ultimate SD upscale) тайл 768, перекрытие 64
23. Двухпроходный апскейл вместо одного большого шага
24. Финальная резкость unsharp 0.3-0.6 px, не больше
25. Экспорт PNG, затем JPG q92 при необходимости

## img2img и inpaint
26. Denoise 0.2-0.35: лёгкая правка, форма сохраняется
27. Denoise 0.4-0.6: заметная переработка, композиция та же
28. Denoise выше 0.75: почти новая картинка (для каракулей)
29. Inpaint: маска чуть шире объекта (feather 8-16 px)
30. Inpaint only masked, padding 32-64 px
31. Mask blur 4-8 px для шва
32. Склейка: невыделенные пиксели берутся из оригинала
33. Soft inpainting для плавного перехода
34. ControlNet Canny/Lineart для каракулей, вес 0.6-0.9
35. ControlNet Depth для сохранения объёма
36. ControlNet Tile для апскейла без смены лица
37. IP-Adapter только со своим или лицензионным референсом
38. Сохранять размер исходника, не ресайзить без нужды
39. Работать в линейных 8-бит sRGB без смены профиля
40. Контрольная проверка diff: вне маски разница = 0

## Лицо и руки
41. Face detailer (ADetailer) после основного прохода
42. Denoise для лица 0.25-0.4
43. Разрешение кропа лица 512-768
44. Hand detailer / отдельный проход для рук
45. Руки меньше в кадре или частично скрыты, если модель ошибается
46. Описывать позу рук словами: «руки сложены»
47. Глаза: симметрия, блики одинаковые в обоих глазах
48. Зубы: естественная неровность, не идеальный ряд
49. Возраст и пропорции указывать явно (только взрослые)
50. Не использовать лица реальных людей без согласия; только вымышленные
51. Один главный субъект в кадре: меньше артефактов
52. Средний план стабильнее макро и дальнего плана для лиц
53. Fix face без смены идентичности: низкий denoise
54. Многолюдные сцены: детейлер по каждому лицу отдельно
55. Волосы: описывать длину, фактуру, пряди, выбившиеся волоски

## Кожа
56. Поры, микрорельеф, лёгкая асимметрия
57. Subsurface scattering: тёплый просвет на ушах и носу
58. Естественные дефекты: веснушки, родинки, мелкие морщины
59. Без «beauty filter»: избегать flawless, perfect skin
60. Блики на коже матовые, не жирные
61. Оттенок кожи по освещению, не фиксированный цвет
62. Тональные переходы: румянец, тени под глазами
63. Лёгкий шум плёнки вместо плоской гладкости
64. Волосы на руках и лице, пушок
65. Текстура ткани и кожи различимы при 100%

## Свет
66. Мягкий боковой свет окна (Rembrandt/loop)
67. Золотой час: направленный тёплый, низкий угол
68. Пасмурный рассеянный свет: ровная кожа
69. Контровой свет с лёгким ореолом
70. Один главный источник + заполняющий
71. Цветовая температура 3200K-6500K по сцене
72. Тени с цветом (холодные), не чёрные провалы
73. Жёсткий полуденный свет только с пояснением
74. Отражения в глазах от источника (catchlight)
75. Согласованные направления теней у всех объектов
