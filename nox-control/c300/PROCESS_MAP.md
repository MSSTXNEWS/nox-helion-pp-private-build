# PROCESS_MAP: карта процессов оркестрации NOX (A2)
Сервис субисполнителей: nox_agents.py, :8810 (SQLite-книга, диспетчер-1 с lease, страж-диспетчер, до 10 очередей). Вход: чат `/команда`, POST /task, /team.

1. Чат -> паспорт намерения (verb/объём/запреты/что остаётся) -> план (1 вызов) -> сверка плана с фразой (дрейф -> доработка) -> один вопрос владельцу только при неясности.
2. План -> подзадачи -> очередь -> исполнитель (роль) -> ревизор (детерминированный verify, затем судья) -> тренер -> карточка «Принять / Доработать / Откатить» с артефактом.
3. **Бриф Методолога** (обязателен для КАЖДОГО субисполнителя): `state/playbooks/_base.yaml` + плейбук типа задачи (cleanup, server, page, coder, writer, ...) подмешиваются в системный промпт в `execute()`; в журнале шаг `brief`. Пункты: фундамент (среда -> готовое из сети -> оптимизация основы -> функции -> проверка и урок); только готовое; офлайн/на копии, на прод одним пакетом, долгое в фоне; «добавь» != «останови/перенеси»; чистки по белому списку с проверкой импортов; владельцу только деньги/доступы/удаления.
4. **Микро-коуч** `coach()`: после каждого вывода исполнителя сверяет с брифом; отклонение (стоп/удаление без просьбы, прямая правка прода, вопрос не про деньги/доступы/удаления, >150 строк своего кода без библиотек, много файлов на повторной попытке) -> шаг `coach` и короткий толчок («смени подход», «собери пакетом», «возьми готовое»), один раз на подзадачу. Счётчик `coach_nudges` в /metrics.
5. Советники/консилиум: шлюз :8793, волны 3 -> старший. Старшие по рисованию: роли drawing_senior_gen / drawing_senior_critic (см. ADVISORS_EXT.md).
6. Черви/охота и самоулучшение: nox_worms.py (:8810/worms), карточки «Разрешаешь?».
Статус пунктов V1: см. ORCH_PLAN.md (дополнения A2 внизу).
