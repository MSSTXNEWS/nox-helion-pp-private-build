# LESSONS: уроки NOX (Reflexion: что случилось -> почему -> правило)
Живое хранилище на сервере: state/lessons.jsonl (S03-поток), правила дублируются в state/playbooks/_lessons.yaml и попадают в бриф Методолога каждого следующего субисполнителя; пары (что -> правило) пишутся в state/night_pairs.jsonl для ночного обучения. Источники: возврат ревизора, поправка коуча, эскалация, зависание, поправка владельца. Повтор того же правила = «повтор ошибки» (метрика repeat_rate в /inspect).
## Стартовые уроки
- Чистка удалила ops/draw -> правило: проверка импортов до удаления, только по белому списку.
- «добавь» понято как «останови/перенеси» -> правило: «добавь» ничего не останавливает, текущее продолжается.
- Один шаг на один запуск Actions -> правило: собирать 5-10 действий в один скрипт, долгое в фоне nohup, результат забирать коротким запуском.
