Живое хранилище на сервере: state/lessons.jsonl (S03-поток), правила дублируются в state/playbooks/_lessons.yaml и попадают в бриф Методолога каждого следующего субисполнителя; пары (что -> правило) пишутся в state/night_pairs.jsonl для ночного обучения. ## Стартовые уроки
- Чистка удалила ops/draw -> правило: проверка импортов до удаления, только по белому списку.
- «добавь» понято как «останови/перенеси» -> правило: «добавь» ничего не останавливает, текущее продолжается.
- Один шаг на один запуск Actions -> правило: собирать 5-10 действий в один скрипт, долгое в фоне nohup, результат забирать коротким запуском.
- (U) add() искал "nox-$2.js" и принял nox-live.js за nox-k8-live.js -> K8live не подключён, QA упал, index откатился -> правило: проверять подключение по точному имени файла (./nox-k8-X.js).
- (U) QA index на 390 попал на редирект в chat -> ложный откат -> правило: на мобильном открывать index.html?home=1.
- (U) /img/generate при обучении отвечает {"error":"korea_img_disabled","reason":...}, студия молчала -> правило: показывать пользователю error/reason; /vision/describe отвечает {"text":...}.
- (U) /svc/advisors/* в браузере ведёт на сервис «advisors» (pins/base), не на шлюз :8793 (images/generations -> {"ok":false}) -> правило: перед встраиванием проверять маршрут из браузера, не только localhost.
- (U) Мобильный fix() шрифта/целей срабатывает на childList, поздние элементы (баннер чата, виджеты, редактор) пропускает -> правило: добавлять периодический проход и наблюдатель атрибутов.
- (U) LESSONS.md был перезаписан чужим коммитом -> правило: только дописывать (>>), перед пушем pull --rebase и проверять grep своих строк.
