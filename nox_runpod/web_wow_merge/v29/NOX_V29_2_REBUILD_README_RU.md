# NOX HELION · V29.2 — проверенная офлайн-сборка

Включены **реальные** исходники V29.2, скрипт сборки, проверка ZIP/SourceLock (1085 файлов), безопасный Windows staging и тесты. Комплект НЕ создаёт новый сервер, не перезаписывает `C:\NOX\helion`, не затрагивает модели, S03 и GPU.

**Исходный WEB V28 (85 149 208 байт):** [скачать с приватного Google Диска](https://drive.google.com/file/d/1YBOJYNzvsjnhzg5TAZj7iL2h543NgOe0/view).

Расположить V28 в `C:\NOX\incoming\NOX_HELION_WEB_V28_V27_PC_GENESIS_UNIFIED_SOURCE_20261113.zip`. Распаковать этот комплект в отдельную папку, затем запустить `NOX_V29_2_REBUILD.cmd`. Он проверит точный исходный SHA V28, создаст V29.2, сверит внешний SHA + внутренний манифест и поместит сайт **только в staging**.

**Эталон V29.2:** 85 217 685 байт, SHA-256 `3379770d33d56e501d267c2ca603d58bce0e301b2582b6585c1944d5f5ec57d0`. ZIP в текущем Vercel Sandbox собран и физически проверен. Если на локальной Python/zlib-сборке выйдет иной compressed SHA, автоматическая приёмка намеренно остановится (хотя файлы могут совпадать); точный ZIP можно взять из Vercel через авторизованный `vercel --scope msttx sandbox cp`.

**Проверено для исходников:** V28 1080 файлов, 1076 без изменений, 4 HTML-изменения, 9 новых файлов; 1085 внутренне закреплённых SHA; 38 активных HTML без битых статических ссылок; локальные HTTP 17/17; API-контракты PC/S03; Chromium 5/5 тестов. Эти факты НЕ означают Windows E07 или обученные веса.

**Приёмка на Windows:** скрипт `NOX_V29_2_WINDOWS_STAGE.ps1` подтверждён Windows CI на уровне синтаксиса и проверки отказа при отсутствующем ZIP. После staging нужно отдельно проверить OneHost/WebView2, все 14 миров, STOP, S03 после перезапуска, голос RU/ES, SAFE70, реальный training optimizer и один EXE SHA. Production не продвигается без такой приёмки.
