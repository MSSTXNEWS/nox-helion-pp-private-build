# NOX V78 — Интернет-учителя через существующий OneHost

**SOURCE ONLY.** Новая служба, основной чат, база и планировщик не создаются. NOX остаётся единственной пользовательской моделью.

1. OneHost может получить **только метаданные** модели из доверенного Hugging Face Hub API через существующий сетевой клиент: id, полный commit SHA, лицензия, gated flag, наличие remote code. Интернет-текст и карточки моделей не выполняются как команды.
2. Проверка `discover_candidate` выдаёт CANDIDATE_REVIEWED_NOT_INSTALLED, не означает загрузку. Требуются конкретный pinned revision, разрешённая лицензия и аудит модельного файла, SHA, квоты и прав. Скачивание — только отдельной native-командой с owner-grant, предпочтительно в PC cold vault, **не на почти полном Vast**.
3. После установки OneHost подключает модель через проверенный локальный/частный teacher endpoint с TLS или приватным туннелем, не через публичный незащищённый порт. `TeacherPorts` — адаптер к уже существующим native callbacks; `native_teacher_infer` обязан применять timeout, rate limit и safe STOP.
4. При сложном вопросе NOX может запросить помощь **только после разрешения владельца на внешний запрос** и проверки privacy scope. Приватная S03 и полные диалоги наружу не пересылаются. Главная модель должна отвечать самостоятельно при HOLD/недоступном учителе.
5. Внешний ответ независимо проверяется, а запись provenance/оценки подтверждается S03 readback. Необработанные teacher-ответы нельзя считать истиной и нельзя автоматически импортировать в тренировочный корпус. `TEACHER_HELP_AND_S03_VERIFIED` означает улучшение доступного опыта, **не новые веса**.
6. Для изменения собственных весов NOX: существующий V39 `propose_distillation` → проверенные права на датасет/приватность, split train/holdout, независимый baseline → native FORGE → реальный optimizer step и проверка изменённого checkpoint + rollback. Никаких LoRA/адаптеров. На V100 учитывать SM70/CUDA12/FP16 и доступную VRAM; active GGUF не является обучаемой HF-базой.
7. GPU0 и быстрый чат P0, учитель по запросу на свободных ресурсах P1, FORGE — только при проверенном admission и no-loss backup; доступ к S03 и STOP сохраняются.

Реальная установка требует от OneHost существующих callbacks и owner approval. Этот коммит не запускает обучение, не скачивает модели и не изменяет работающий сервер.
