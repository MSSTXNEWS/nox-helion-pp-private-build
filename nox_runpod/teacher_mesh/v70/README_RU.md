# NOX HELION V70 · ONEPASS / максимальная скорость с сохранностью

**Один NOX PRIME → один «Резонанс» → одна основная GGUF-модель → S03.** Учителя, дистилляция, резервные копии и синхронизация уступают чату. Второго backend, GPU scheduler или пользовательского чата V70 не создаёт.

## Выполнение на Vast.ai (единственный GitHub Actions запуск)

`.github/workflows/nox-v70-onepass-cold-ram-offsite.yml` выполняет всё сразу: 7 offline проверок, выделяет временный SSH-ключ из действующего API Vast (NOX2), выбирает **ровно три неиспользуемых** холодных файла (2 backup .gz и 1 incoming .zip, суммарно 415 521 256 байт), проверяет процессные FD и неизменность входных файлов, использует `TemporaryFile(dir=/dev/shm)` c `nice(12)`, отправляет зашифрованный поток к ключу владельца V60/V69, тестирует *все 3 SHA* путём расшифровки вторым временным ключом и делит ciphertext на 6 частей по 70 MB. За один workflow запускается только один SSH-сеанс успешного переноса; при сетевых ошибках допускаются ограниченные попытки с обязательным отзывом ключа.

Данные **не удаляются с Vast в этом запуске**. GitHub runner не имеет подключённых прав Google Drive и не может автоматически загружать файлы в Drive; этот этап выполняется штатным коннектором после получения шести артефактов. Нельзя называть checkpoint/модель сохранёнными, если скопирован только cold backup.

## Перенос с Google Drive на реальный Windows ПК

После выгрузки шести зашифрованных ZIP-частей в [каноническую приватную папку NOX](https://drive.google.com/drive/folders/1CK8B-KOasziDFMvcamt8vuNQxpjpmTuR) распаковать Windows-пакет и **один раз** запустить `NOX_V70_ONEPASS_PC.cmd`.

- Скрипт `NOX_V70_PC_ALL_ONEPASS.ps1` автоматически выбирает несистемный HDD с достаточным пространством; поддерживает существующий Google Drive for Desktop либо единственный настроенный `rclone` remote. Новый токен и пароли не запрашивает.
- Одним запуском использует существующий приёмник для V60/V61/V69 (6 ZIP), затем скачивает V70 (ещё 6 ZIP), проверяет SHA содержимого каждой части, собирает V70 ciphertext как бинарный `.tar.age`, проверяет общий SHA, пишет `NOX_PC_V70_ALL_OFFSITE_SHA_RECEIPT.json`.
- Не удаляет оригиналы, не останавливает службы, не запускает обучение, не загружает модели, не меняет S03.
- Без входа в Google Drive на самом ПК честно возвращает HOLD. До получения локального SHA-отчёта физический перенос на пользовательский диск **не подтверждён**.
- Правильность owner SSH private key для `age` должна проверяться отдельно; совпадение SHA ciphertext на ПК не означает полного восстановления весов/optimizer.

**Запрещено:** удалять живой `current.gguf`, базу S03/WAL, уникальные веса и checkpoints; использовать RAM как постоянную копию. Установка новых вторых служб не требуется.
