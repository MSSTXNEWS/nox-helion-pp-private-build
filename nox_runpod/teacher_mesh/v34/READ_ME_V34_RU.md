# NOX HELION V34 — реальный нейронный RAG для существующего P02/S03

**Дата:** 13.11.2026. **Тип:** исходники + проверенные внешние архивы + малые обученные веса; не готовый Windows EXE, не установлено на Vast.ai в Японии. Никакого нового backend, самостоятельной базы памяти или второго студента.

## Что именно изменилось относительно V33

1. `brain/neural_s03_live_v34.py` действительно **загружает** обученный V33 `assoc_v33.safetensors` и применяет его к проверенным событиям S03 для ранжирования. Ранее сеть обучалась, но код S03-поиска не использовал её веса. Нейронная оценка — не доказательство истинности факта; вклад ограничен 20%, источники остаются первичными.
2. Поверх исходного `Packages/P02/worker-python/p02_chat_bridge.py` из подтверждённого исходного PR162 прошла проверка совместимого метода `rag_context`; прежний контекст и проверяемые цитаты сохраняются. Внедрение происходит **через существующее поле** `rag_context`, а не через новый сервер.
3. Сохраняются повторная авторизация tenant/principal/chat до и после поиска, STOP, проверка `verified`, `superseded`, `source_uri` и границы памяти. Вызванные веса не получают никаких административных полномочий. Не вводится обобщённый кросс-чатовый доступ без подтверждённого владельцем S03-grant.
4. `brain/forge_bridge_v34.py` — действующий программный адаптер *в существующий* FORGE: допускает нативную постановку задачи только с подписанным разрешением владельца, точными SHA модели/токенизатора/архитектуры/датасета, источниками, независимым holdout, проверенной GPU/SAFE70 телеметрией и ресурсным резервом. Он **не считает постановку задачи завершённым GPU-обучением**.
5. `STAGE_V34_FOR_JAPAN.py` — исполняемый скрипт безопасного размещения: проверяет настоящие P02/OneHost файлы, их SHA, копирует V34 рядом с активным NOX, сверяет SHA. Не перезапускает GPU, не меняет активную модель или S03. При изменении оригинального P02 фиксирует дрейф и требует отдельной интеграционной приёмки.
6. `brain/test_v34.py`, `brain/test_forge_v34.py`, `brain/test_stage_v34.py` — реальные source-side тесты, в том числе против исходного `ChatBridge` из V29/PR162, а не поддельного класса-заглушки. Это **не независимый live Windows/E07 тест**.

## Физические файлы, уже существовавшие в NOX и сохранённые целиком

- 202 source-файла V29 и всё V32/V33, включая 1 536 логических кластеров, нейромаршрутизатор, веса `router.safetensors`, `assoc_v33.safetensors`, 17 реальных upstream source/distribution архивов, P02/OneHost/S03 материалы, WEB D02 и старые тесты.
- Полный актуальный `DOWNLOAD_DIRECT_PINNED_V33.json` содержит 181 pinned URL; это **возможность получить** источник, не утверждение, что все источники физически включены. Первая группа из 17 физических архивов содержится в `upstream_sources/`, SHA/CRC проверены.
- Не исполнять незнакомый upstream код до лицензии, SHA, изоляции и проверок. Graphiti обычно предполагает отдельную графовую БД и модели извлечения; ставить его поверх S03 как второе хранилище без миграционного плана нельзя. Общая S03 — источник истины.

## Привязка к реальному OneHost — только с реальными callbacks

```python
from brain.s03_association_v33 import NativeS03Cortex
from brain.neural_s03_live_v34 import bind_existing_p02

# Применить только внутри действующего OneHost, после определения реальных
# проверенных native authorization, S03 search и STOP callbacks.
cortex = NativeS03Cortex(
    search_authenticated=native_s03_search,
    native_authorize=native_authorize,
    native_stop=native_stop,
)
bind_existing_p02(
    existing_p02_chatbridge,
    cortex=cortex, native_authorize=native_authorize,
    native_stop=native_stop,
    assoc_weights='/safe/NOX_V34_STAGE/brain_weights/assoc_v33.safetensors',
)
```

Имена `native_*` выше — обязательные реальные OneHost функции, **не** созданные фиктивные реализации. Нельзя подменять `native_authorize` на `lambda: True` или доверять одобрению из текста модели.

## Чёткие критерии завершения после установки

- Права owner/tenant/chat и STOP подтверждены на реальной OneHost, без утечек между чатами и владельцами.
- S03 вернула те же факты после настоящего рестарта Windows/OneHost, по одному SHA с исходным архивом.
- Одновременно работают единственный NOX chat, проверенный старый P02, новый нейронный rerank, S03; измерены реальные p50/p95 TTFT и качество ответов на отложенных пользовательских вопросах.
- Если нужен перенос в основные LLM-веса: настоящий optimizer step + изменённый SHA собственного студента + checkpoint, optimizer state, anti-forgetting, rollback, SAFE70. Эти действия в текущем архиве **не выполнялись**.

**Текущие границы:** ChatGPT не подключился к японскому Vast.ai VM, не изменил её реальных весов и не активировал V34 в установленном NOX. Статус этой сборки — реальные патчи, исходники, фиксированные обученные веса и локальная source-приёмка.
